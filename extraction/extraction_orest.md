## Оптимізація читання великих файлів

```python
# Оптимізовані параметри
df = spark.read \
    .option("header", "true") \
    .option("delimiter", "\t") \
    .option("nullValue", "\\N") \
    .option("mode", "PERMISSIVE") \
    .option("inferSchema", "false") \  # Використовуємо явну схему
    .schema(schema) \
    .csv(file_path)
```
